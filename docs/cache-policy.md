# 翻译缓存策略

设置中心“网站与缓存”提供缓存有效期、最大条目数与重启清理开关。

- 有效期单位为秒，默认 604800（7 天），允许 0 至 31536000。0 表示不按时间过期，仍受条目上限、手动清理与重启清理控制。
- 默认最多保留 2000 条，允许 1 至 10000。超过上限后按写入顺序移除最早条目；更新条目会将其移动至队尾。
- 缩短有效期从下一次缓存操作开始生效；延长有效期或改为永久不会延长已有条目写入时的期限。
- 新条目在响应头记录创建时间及到期时间。读取时拒绝并删除已过期条目。
- 没有时间元数据的历史条目按失效处理，在首次维护扫描中删除。后台重新启动后会重新执行扫描；后续最多每分钟扫描一次，配置改变后下一次操作立即重新扫描。
- 手动清理等待后台删除完成后才提示成功。重启清理与定时过期相互独立。
- 缓存操作在后台串行执行，防止并发写入突破条目上限或清理与先前写入发生竞态。清理完成后新产生的写入可以重新建立缓存。

当前限制为条目数量，不是精确字节配额。缓存读取始终检查该条目是否过期；维护扫描无需后台定时器，未使用扩展时不承诺按时物理删除。
