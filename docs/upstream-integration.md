## v2.1.1 关联能力

- 富文本与行内图片：当前 Renderer/Scanner 使用白名单重建与原节点备份。
- 批处理取消：请求使用每任务 AbortSignal、配置兼容性检查和后台取消，并清理重试等待的任务与定时器。
- 术语缓存、生词本、WebDAV、Requesty、网站规则可视化编辑、全站 Material 3 重构：不属于当前产品模块。

## 架构冲突清单

1. 上游的插件服务选择/能力解析、Offscreen Broker、Worker 与 WASM 模型管理不是当前 Provider 注册表的直接替代品。搬入会同时影响后台消息、设置迁移、权限和产物校验。
2. PDF/EPUB/图片翻译依赖文档工作区、桥接页面、识别/版面分析、文档导出及额外资源构建。当前项目没有这些入口，不通过复制代码制造不可用菜单。
3. YouTube 新采集/音频转写/字幕持久缓存依赖新桥接协议、ASR 会话和新服务模型。兼容的 fetch 捕获已接入既有消息通道；其余不叠加到当前缓存身份与请求生命周期之上。
4. Claude、其他新增 Provider、生词本和多端同步不在当前产品模块中，对应修复没有可落地的现有路径。
5. 上游多客户端、多站点构建和全站主题没有替换本项目 Chrome 单目标发布规范与设计系统。

## 验证边界

单元测试与构建校验覆盖可兼容分支和产物结构。真实 YouTube 页面、服务可用性、浏览器崩溃及默认模型可用性需要独立运行验证，不能由单元测试证明。受控调度基准的边界和数据见 `performance/README.md`。
