# 设置与翻译面板

LingoFlow 使用暖米白背景、陶土色强调、双色标记、衬线标题和轻量设置分区。侧栏菜单与分组标题使用与页面标题相同的衬线字体。

## 交互约定

- 普通偏好自动保存；翻译服务保留现有草稿、显式保存和连接测试。旧 `/apis` 地址跳转到统一的 `/providers` 编辑页面。
- 通用设置、网页规则和悬浮按钮共用存储写入反馈；顶部状态显示保存中或已保存，失败提示列出具体来源，后续成功写入同一来源后清除该错误。
- 界面文案覆盖设置中可选的简体中文、繁体中文、英语、日语、韩语与土耳其语。
- 网页和文本翻译页签保持组件挂载，切换不清空文本输入。首词和后续流式输出不添加逐字动画，也不等待界面过渡。
- 高级选项使用 200ms 网格高度过渡，保留未保存字段，收起时排除隐藏区域的焦点和指针交互。
- 页签选中底板移动 180ms，内容轻入场 140ms，开关切换 160ms；页面内浮层淡入 160ms、淡出 100ms。减少动态效果模式关闭这些过渡。
- 开关的透明点击区域限制在控件内，避免缩小控件后沿用 MUI 的默认宽点击区造成页面溢出或误触。

## 信息组织

- 常规页：语言、默认翻译服务、显示方式、悬浮按钮；扫描、超时和日志等参数进入高级区域。
- 服务页：左侧列表、右侧连接表单；排序和批量操作进入列表管理；请求、批处理、提示词及开发参数保持可访问。
- 数据与缓存、快捷键和关于页面分别提供独立入口。赞赏入口位于关于页。
- 字幕页保留样式编辑与预览，统一高级区的展开方式；AI 断句和背景摘要按可用 AI 服务显示。
- 900px 以下侧栏改为抽屉；设置行允许在更窄空间中换行。

## 运行边界

页面预览可在本地 HTTP 环境中渲染；后台消息、网页注入和跨标签页同步依赖扩展安装环境。本地页面预览不能替代真实网页上的翻译与字幕验收。
