# 目标语言自动翻译

浏览器弹窗、网页内悬浮面板和设置中心的“语言”区域使用同一个“目标语言自动翻译”开关。开关默认开启，修改后保存到本地配置，并通知已打开的页面重新读取设置。

开启后，扩展检测网页主体的语言，将符合条件的页面自动译为当前网页规则中的目标语言。例如，目标语言为简体中文时，英文、日文、法文页面均可自动翻译；目标语言改为日文时，后续自动翻译使用日文。

以下页面不会因此自动开启翻译：

- 页面已经使用目标语言。语言比较沿用整页翻译的语言族判断，简体和繁体中文视为同一语言。
- 页面语言在“忽略语言”列表中。
- 页面没有有效正文，或者未能检测到受支持的语言。
- 网页规则指定了固定源语言，但检测结果与该源语言不符。

修改当前网页规则的目标语言后，会重新判断是否需要自动开启翻译。“预先初始化”开关不影响自动翻译判断。语言检测尚未结束时关闭自动翻译或停止页面翻译模块，会阻止过期结果启动翻译。

关闭自动翻译开关会取消自动启动偏好；手动翻译和网站规则中的“开启翻译”仍按各自设置执行。

配置字段已由 `autoTransEnglish` 改为 `autoTransTarget`。旧配置读取和写回时会转换旧字段，保留原来的开启或关闭偏好；同时存在两个字段时，以新字段的布尔值为准。界面文案同步支持简体中文、繁体中文、英文、日文、韩文和土耳其文。

此开关控制整页网页翻译。划词翻译与 YouTube 字幕使用各自的目标语言和开启设置。
